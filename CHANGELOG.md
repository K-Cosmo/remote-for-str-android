# Changelog

## 0.1.0 - 2026-09-26

### Added

- Initial Android MVP.
- STR discovery via `_streborn._tcp` and legacy `_soundtouchstick._tcp`.
- 8888 -> 17008 reachability fallback.
- Multi-speaker picker and manual host entry.
- Last-speaker persistence.
- Hardened WebView wrapper around the existing STR phone remote.
- Android 17 local-network permission support.
- German and English strings.
- GitHub Actions debug build.
