# Privacy

STR Remote does not operate a server, create user accounts, collect analytics or transmit telemetry.

The app accesses the local network to discover and connect to SoundTouch Reborn speakers. The embedded STR web application may perform its own network requests required by STR features; STR Remote does not collect those requests.

STR Remote stores local speaker metadata in Android app-private preferences. This includes the last selected endpoint and, when the user explicitly saves speakers, their local host, port, display name, model/discovery identifier and optional room assignment. A custom room name is stored exactly as local user-entered text. Saved-speaker and room metadata is not uploaded or cloud-synced by STR Remote.
