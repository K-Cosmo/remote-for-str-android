# Specification — first public release preparation

Prepare the verified STR Remote MVP for a first public `0.1.0` release without adding functionality. `/doc` remains the sole normative source of truth.

Required outcomes:

- use a public release-candidate version (`0.1.0-rc1`);
- provide a useful GitHub README for users and contributors;
- make SoundTouch Reborn an explicit prerequisite and clearly separate upstream vs wrapper responsibilities;
- publicly disclose the AI-assisted development model without suggesting the runtime app uses AI;
- preserve the thin-wrapper architecture and current permission/security boundaries;
- converge BUILD-0002 evidence into `/doc`;
- identify, rather than hide, the remaining release gates.
